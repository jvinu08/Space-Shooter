Space Piggies
A space shooter game built in C# as my Grade 11 Computer Science project. Pigs. In space. Need I say more?
 About the Game
Take control of a spaceship and blast through waves of enemies across multiple levels. Built entirely from scratch in C# Windows Forms.
Features

Multiple levels (Level 1, 2 and 3)
Enemy wolves to defeat
Menu screen and game states
Increasing difficulty across levels
Game over screen

Built With

C#  Windows Forms
Visual Studio

How to Run

Clone or download this repository
Open the .sln file in Visual Studio
Hit Start to build and run

What I Learned
My first ever game built from scratch in Grade 11. This project taught me:

C# fundamentals and syntax
Working with images and game assets
Managing multiple game states (Menu, Pause, Game Over)
Structuring a project across multiple classes
Thinking like a programmer breaking a big idea into small solvable problems
